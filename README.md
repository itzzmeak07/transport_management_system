# Transport Management System (FreshTrack)

Transport management system for perishable goods shipped from Solapur to dealers across India: admin web panel plus an Android app for vehicle owners, drivers and dealers. Trucks deliver to one or more dealers in an order the admin sets.

## Design preview

The UI mockups are in [`docs/`](docs/) and published with GitHub Pages:

**https://itzzmeak07.github.io/transport_management_system/**

- `docs/index.html`: list of all design boards
- `docs/FreshTrack_All_Designs.html`: every board on one page
- `docs/png/`: an image of each board
